Compare the ideal edge surface with the computed edge surface.
The parameters on the command-line must be:
1) the image file with the ideal edge surface
   (this image has values 0 and 255 only).
2) the image file with the computed values
   (this image may have all the range of values 0..255)
3) opzionally, a threshold, or a list of thresholds,
   to be applied to the computed values
   (pixels with value<threshold are considered as 0),
   each threshold must be a natural number.
   if no threshold is present, 0 is used
All images must be 64 x 64 x 64 voxels and in vtk format.

Precision and recall are computed:
 EXACT = according to definition
 D2    = within distance 2
 D3    = within distance 3
